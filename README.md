# Spreadsheet Transfer Reminder

Google Sheets × Google Apps Script × Discord

スプレッドシートのセルの背景色を利用した、資金移動リマインダーシステム。

## 開発背景

複数の銀行口座を管理する際、口座間の資金移動を忘れないよう、自動通知する仕組みを開発しました。

既存のスプレッドシートをそのまま活用し、新たな入力作業や管理負担を増やさないことを重視しています。

## 主な機能

- 指定された背景色のセルを自動検出
- 資金移動元・移動先・金額の取得
- 入金側の記録を除外し、通知の重複を防止
- 日付が空欄の追加行にも対応
- 年をまたぐ日付の判定
- 資金移動予定日の前日にDiscordへ通知
- 複数の資金移動予定を1通に集約
- 通知対象がない場合は送信しない
- 時間主導型トリガーによる自動実行

## システム構成

Google Sheets  
↓ データ・背景色の取得  
Google Apps Script  
↓ 日付・条件判定  
Discord Webhook  
↓ メッセージ送信  
Discord

PCを起動していなくても、Google Apps Scriptによって自動実行されます。

## セキュリティ対策

- Webhook URLはスクリプトプロパティに保存
- Discordはプライベートチャンネルを使用
- スプレッドシートのデータは読み取りのみ
- 実際の銀行振込は自動化せず、本人が手動で実施
- 公開用コードには個人情報や実際の家計データを含めない
